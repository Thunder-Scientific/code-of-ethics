# Introduction

## Welcome to the Code of Ethics

The Code of Ethics (often abbreviated to CoE) is a ruleset written and maintained by the Thunder Scientific Corporation Ethics Committee. It serves as the base rules and as a standard to uphold for all personnel in the Corporation.
To ensure a lack of bias and fair punishment, **all personnel, with the sole exception of the Administrator, are subject to the Code of Ethics at all times, unless in terms which apply to their job.**

The Code was created by the Ethics Committee to ensure the Corporation would not fall into chaos and distrust despite the challenging and uncertain circumstances it survives in. TSC must remain strong, for humanity's sake.
