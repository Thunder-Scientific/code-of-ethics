# Rule E2 | Combatant Escort Procedures

Combatants should only ever decline escorting a test if they have a valid reason. Valid reasons for declining a test escort are as follows:

- The RsD requesting the test is an Trainee or if the MD requesting a checkup is below the rank of Nursing Student without a supervisor
- The TSCZ/CISCZ would not be properly secured without the combatants in question (At least 2 security must remain inside TSCZ to guard)
- The only available combatants do not have the necessary tools to secure the test
- There is currently an identified CIS or breached specimen in the TSCZ or around it
- The situation in TSCZ is nearing a riot OR there are multiple problematic TS causing problems within the TSCZ
- There is currently an event in which SD personnel are partaking UNLESS said event involves testing
- There is an identified breached and confirmed hostile specimen somewhere in the CTZ
- There is an ongoing sitewide emergency i.e.: Breach, Raid, Riot, CTZ Lockdown, etc...

If a combatant is seen denying test escorts for minuscule reasons, such as a personal grudge against the RsD in question, they will get infracted by EC. However, said combatant may be given more leniency on that, provided they have a good reason which is not specified on this list. If the reason provided by the combatant is seen as not fit, the combatant will be infracted.

---

During any on-site event, the combative ratio of Infected Subject (IS) or Test Subject (TS) should be the following:

Normal Security Forces : Test Subjects > 1:3

Recontainment Unit/Special Operations : Test Subjects > 1:4

Juggernaut Unit : Test Subjects > 1:8

Recontainment Unit/Technical Task Squad : Infected Subject  > 1:3

Juggernaut Unit : Infected Subjects > 1:6

Only paired RAH assets may escort hadron tests when requested by the host. RAH ratios are as follows:
Light Pairs: 1:6 Test Subjects, 1:4 Infected Subjects
Heavy Pairs: 1:8 Test Subjects, 1:6 Infected Subjects

Each combatant present in a test escort increases the maximum ratio by 1. Example being is if there’s 3 Normal Security Forces escorting a test, they would be able to escort 11 TS in total (3 + (3+1) + (3+1).

RSD Do not follow the rules above and instead have full control over their own escort ratios, further information about the ratios can be found in the [RSD Handbook](https://trello.com/c/Hk7ZOD2t/29-combatants-escorting "‌").
