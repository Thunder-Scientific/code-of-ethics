# Rule E1 | Test Shutdowns

Research and Studies Department personnel are permitted to violate all **except for** the Behavioral Guidelines and Abuse & Misconduct sections (A & F) of the Code of Ethics during active testing as long as all combative escorts consent to it and it doesn’t threaten site operations. _RsD personnel may violate section F if it's within reason, for example: giving TS weapons for a test procedure._

Additionally, RsD is freely permitted to test personnel with their consent. If a Researcher decides to use personnel, they are to fully abide by their wish to withdraw consent at any time.

If a section of the Code of Ethics is going to be violated, you must inform everyone present during the first briefing. This is to prevent anyone from being told too late or not told at all, which could lead to miscommunication and infractions, or slowing down the research efforts.

Ethics Committee Agents may intervene when there’s an actual threatening situation: the researcher is risking a breach, cramming infected into a tiny room, etc. Minor mistakes will attempt to be corrected first instead of shutting down the testing and RsD HRs will be contacted.

Note: This exemption only applies to the actual RsD performing the valid testing. RsD personnel will be held liable for Code of Ethics violations if their testing is unauthorized.

---

Ethics personnel withhold the right to shut down a test for the following reasons:

- The test or person responsible for the test is directly violating the Code of Ethics not outlined in the exceptions listed above
- The test is insufficiently secured for the risk involved, i.e. the test is not following RsD escort regulations:
- ⚬  _4 TS per each Primary / Secondary escort_
- ⚬  _5 TS per each High Priority escort_
- ⚬  _8 TS per each Juggernaut Unit (JU)_
- The test host is attempting to access a high-security area without the correct RsD ranking
- Test Subjects have not received a full briefing
- Site security level was set to code GAMMA or above

In an emergency, Ethics personnel can shut down a test for other reasons, given they can explain their actions afterward.

---

In the event of the EOP system being changed to code RED, the host must stop the event and evaluate if the threat is located in the sector their test is currently located in. If the threat is located within their sector, the following procedure must be carried out for the test by the present staff:

1. Inmates must either be terminated, returned to their containment zone, escorted to a secure location, or left at the site of the event at the discretion of security staff.
2. Present security staff should escort all non-combatant personnel present at the event to a safe area.
3. Once the event has been terminated and all staff are safe, security staff should proceed with their regular response to the type of incident,
4. If the test has already made its way to the Containment Zone and present combatants deem it safe enough to continue the test, the event may be continued.
