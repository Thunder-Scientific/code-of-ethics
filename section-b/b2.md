# Rule B2 | Emergency Protocols

## Site-Wide Emergency Protocols

In the event of a site-wide emergency, the correct site code color should be activated so the proper announcement be made over the PA system that matches the situation.
Codes do not need to be raised or lowered in order nor does there need to be a set amount of time before lowering the code. (Code can be changed from Gamma down to Blue if there is no more reason for Red or Gamma)

The following Emergency Code Levels currently exist in-game:

**Code Green:**

This is the standard color code for site operations when there are no recognized threats against site stability. When there aren't any threats that pose a danger to site stability, code green should be reinstated and site operations should be continued as normal.

**Code Blue:**

A potential threat is roaming the site with a high probability of posing a threat to site stability. All personnel should have heightened awareness of any possible threats around them, and report them when they are spotted. This status should be set if any of the following conditions apply:

- Armed hostiles were reported to be within the facility
- Contained Infected Subjects are confirmed to be missing from their containment zone
- Large groups of escaped inmates roaming the facility

**Code Red:**

A confirmed threat is roaming the site and is an active threat to site stability. Any non-combatant personnel are advised to vacate the current sector the threat is in, and to make their way to a designated safe area. Security forces may order non-combatants into a safe area if deemed necessary. This status should be set if any of the following conditions apply:

- There is an armed group of hostiles reported on-site actively contributing to site instability
- There is a confirmed Infected outside of the Containment Zone
- Any amount of radiation has breached containment
- A rogue staff member has been reported within the facility

**Code Gamma:**

A highly dangerous threat has been detected in multiple sectors of the facility, and is actively contributing to site instability. No non-combatants may be outside of the nearest designated safe area/panic shelter with an exception of medical personnel in accordance to C1. This status should be set by L-4+ personnel if any of the following conditions apply:

- Any U4 specimen has breached their containment chamber.
  - The “containment chamber” is the room at which the specimen spores reside.
- A large number of hostiles are actively contributing to site instability and normal security forces cannot handle the threat
- A large amount of staff have reported to have gone rogue
- Code Red has been on for a **constant** 40 minutes+ without any sign of the threat(s) causing it being resolved.
  - SD Warrant Officer+ can authorize gamma after code red has been on for a constant 30 minutes

RECON, SO, and JU may set gamma if one of the requirements above are met. (Even if they are not L4+)

Codes past **Code Gamma+** are only to be activated by L5+ Personnel.

**Code Epsilon:**

Full site control has been lost to hostile forces. Any means to get to a designated safe area is permitted even if that means bypassing Code of Ethics rulings based on clearance or self-defense. This status should be set if any of the following conditions apply:

- Most sectors of the facility have been overrun by hostiles
- A full site breach or riot has occurred where no area in the site is considered safe

**Code Delta:**

The situation on site is beyond repair, and the on-site nuclear armaments have been primed to detonate and destroy anything inside the facility. All personnel must evacuate to the surface by any means necessary and security forces should help personnel evacuate and prevent hostiles from escaping to the surface.

The on-site nuclear armaments may only be activated by personnel who possess an administrative clearance (AD+) or SO/SD 2iC+ during the event of when site control cannot be regained after a Code Epsilon has been initiated after at least 20+ minutes. The nuclear warhead detonation is only to be used as a last resort, and may only be activated if the following applies:

- Site control cannot be regained during a **Code Epsilon** after 20+ minutes
- The entire site is compromised, and a member of the Administrative Department gives authorization for a **Code Delta** to be initiated.

If the onsite contingency system is activated without an evacuation announcement, then it is assumed to be compromised by hostile forces and emergency evacuation is to commence unless Security Forces regain control and deactivate the system.

**Code Amber:**

A simulation of the evacuation protocol performed during a **Code Delta** event that is used as a drill to ensure that all personnel present know what to do when an evacuation is called, and should be considered with the same urgency and efficiency for an actual **Code Delta** event.

- A **Code Amber** may only occur with the permission of a member of the Administrative Department and is to be supervised by Security and/or Divisional Command staff
- Before a **Code Amber** is declared, all on-site personnel are to be warned for at least 5 minutes to ensure that any ongoing events are canceled, concluded, or postponed.
- **Code Amber** should only be called up to 2 times per month and should last a maximum of 15 minutes.

A designated safe area is any one of the following:

- A breach or panic shelter.
- A department office that isn't easily accessible to hostile forces.
- Any area designated by present security forces on-site to be considered safe and defend-able from hostile forces as an alternative.
- TSCZ Control Room, Main Control Room in SD U2, and the CISCZ Control room

Personnel should remain in their safe location for the duration of the emergency unless they are:

- Requested and escorted by a combatant for instances of **Code Red** emergencies.
- Forced out of the safe area by hostile forces.
- **Code Delta** has been activated and an evacuation commences.
