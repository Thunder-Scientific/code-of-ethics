# Notice H1 | Testing Exemption

Research and Studies Department personnel are permitted to violate all but the Behavioural Guidelines section (A) of the Code of Ethics  during active testing as long as all combative escorts consent to it and it doesn’t threaten site operations.

Additionally, RsD is freely permitted to test on personnel with their consent.
If a Researcher decides to use personnel, they are to fully abide by their wish to withdraw consent at any time.

If a section of the Code of Ethics is going to be violated, you must inform everyone present during the first briefing. This is to prevent anyone from being told too late or not told at all, which could lead to miscommunication and infractions, or slowing down the research efforts.

Ethics Committee Agents may intervene when it's an actual threatening situation: researcher is risking a breach, cramming infected into a tiny room, etc. Minor mistakes will attempt to be corrected first instead of shutting down the testing and RSD HRs will be contacted.

Note: This exemption only applies to the actual RsD performing the valid testing. RsD personnel will be held liable for Code of Ethics violations if their testing is unauthorized.
